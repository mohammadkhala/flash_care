## قبل التجربة

1. تثبيت النسخة الجديدة فوق القديمة على جوالين (مريض + طبيب)
2. تسجيل خروج ثم دخول على الجوالين (تحديث توكن الإشعارات)
3. إكمال رسالة «حتى تصلك المكالمات وترنّ» (أو: الملف الشخصي ← إعدادات المكالمات)

## سيناريوهات التجربة

| # | السيناريو | النتيجة المتوقعة |
|---|-----------|------------------|
| 1 | الطبيب يتصل (صوت) والمريض داخل التطبيق | شاشة رنين كاملة عند المريض + نغمة انتظار عند الطبيب |
| 2 | نفس الشيء والتطبيق **مغلق تماماً** عند المريض | يرنّ رغم الإغلاق |
| 3 | الشاشة **مقفلة** عند المستقبل | يرنّ ويظهر فوق القفل |
| 4 | «رد» | يفتح التطبيق على المكالمة ويسمع الطرفان بعضهما |
| 5 | «رفض» | عند المتصل: «تم رفض المكالمة» |
| 6 | المتصل يُنهي قبل الرد | يتوقف الرنين عند الآخر |
| 7 | لا أحد يرد 45 ثانية | المتصل: «لم يتم الرد» — المستقبل: إشعار «مكالمة فائتة» |
| 8 | مكالمة فيديو | الكاميرا والصورة عند الطرفين، قلب الكاميرا يعمل |
| 9 | العكس: المريض يتصل بالطبيب | نفس النتائج |
| 10 | طبيب ↔ طبيب (من «الأخصائيون») | نفس النتائج |
| 11 | جلسة موعد: الطبيب «ابدأ الجلسة» | يرنّ عند المريض، أو يدخل المريض من بانر الجلسة |

## ماذا نطلب من المستخدم عند المشكلة

- رقم السيناريو + نوع الجوال وإصدار أندرويد
- لقطة شاشة لما ظهر
- هل أكمل رسالة إعدادات المكالمات؟

## تشخيص سريع

| العَرَض | السبب الأرجح | الفحص |
|---------|--------------|-------|
| لا يرنّ أبداً | توكن FCM قديم، أو الإشعارات مرفوضة | خروج/دخول + `grep "FCM push failed" storage/logs/laravel.log` |
| يرنّ داخل التطبيق فقط | توفير البطارية / التشغيل التلقائي (شاومي، أوبو، هواوي…) | إكمال رسالة إعدادات المكالمات |
| يرنّ كإشعار صغير بدل شاشة كاملة | «شاشة المكالمة الكاملة» غير مفعّلة (أندرويد 14+) | من رسالة الإعدادات |
| يرنّ، والمكالمة تبقى «بانتظار الطرف الآخر» | حساب Agora (المشروع غير مفعّل / انتهى الرصيد) | console.agora.io |
| «غير مصرح لك بإجراء هذه المكالمة» | المستخدم ليس طرفاً في المحادثة/الموعد | `CallChannel::participants('nabd-conv-ID')` |
| «تعذّر الاتصال بالخادم» | السيرفر أو الإنترنت | `storage/logs/laravel.log` |

### فحص آخر المكالمات على السيرفر (قراءة فقط)

```bash
cd /home/sarfesak/public_html/doctor
php artisan tinker --execute='foreach (App\Models\WebrtcSignal::latest("updated_at")->take(5)->get() as $s) echo $s->updated_at." | ".$s->channel." | ".$s->caller_id."->".$s->callee_id." | ".$s->status.PHP_EOL;'
```

الحالات: `ringing` يرنّ · `active` تم الرد · `rejected` رُفضت · `missed` لم يُرد · `ended` انتهت
