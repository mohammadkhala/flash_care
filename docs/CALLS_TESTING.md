## قبل التجربة

1. تثبيت النسخة الجديدة فوق القديمة على جوالين (مريض + طبيب). **لا حاجة لحسابات جديدة** — الحسابات القديمة تعمل
2. فتح التطبيق مرة والحساب مسجّل دخول (يرسل توكن الإشعارات للسيرفر تلقائياً عند كل تشغيل)
3. إكمال رسالة «حتى تصلك المكالمات وترنّ» (أو: الملف الشخصي ← إعدادات المكالمات)
4. بين الحسابين محادثة أو موعد (السيرفر يرفض الاتصال بين حسابين بلا علاقة)
5. كل حساب على جوال واحد فقط — السيرفر يحفظ توكناً واحداً لكل حساب، فالرنين يذهب لآخر جوال فُتح عليه الحساب

### فحص آخر المكالمات على السيرفر (قراءة فقط)

```bash
cd /home/sarfesak/public_html/doctor
php artisan tinker --execute='foreach (App\Models\WebrtcSignal::latest("updated_at")->take(5)->get() as $s) echo $s->updated_at." | ".$s->channel." | ".$s->caller_id."->".$s->callee_id." | ".$s->status.PHP_EOL;'
```

الحالات: `ringing` يرنّ · `active` تم الرد · `rejected` رُفضت · `missed` لم يُرد · `ended` انتهت

### فحص أن Firebase يقبل الإرسال لجوال معيّن (لا يظهر شيء على الجوال)

```bash
cd /home/sarfesak/public_html/doctor
php artisan tinker --execute='
$s=app(App\Services\FcmService::class); $m=new ReflectionMethod($s,"getAccessToken"); $m->setAccessible(true);
$t=$m->invoke($s, config("services.firebase.credentials"));
$u=App\Models\User::find(24);
$r=(new GuzzleHttp\Client(["http_errors"=>false]))->post("https://fcm.googleapis.com/v1/projects/".config("services.firebase.project_id")."/messages:send",["headers"=>["Authorization"=>"Bearer ".$t],"json"=>["validate_only"=>true,"message"=>["token"=>$u->fcm_token,"data"=>["type"=>"test"]]]]);
echo $r->getStatusCode()," ",$r->getBody(),PHP_EOL;'
```

200 = السيرفر والمفتاح والتوكن سليمة. لإرسال إشعار حقيقي: احذف `"validate_only"=>true` وأضف `"notification"=>["title"=>"…","body"=>"…"]` داخل `message`.
