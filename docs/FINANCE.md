## الفكرة

دفتر حسابات للأخصائي داخل تطبيقه (لا يوجد دفع إلكتروني — المريض يدفع للأخصائي مباشرة).
الأخصائي يسجّل الفواتير والدفعات والمصاريف، والمريض يرى فواتيره ودفعاته في تطبيقه («فواتيري»).

## قرارات العميل (2026-10-17)

| البند | القرار |
|-------|--------|
| إنشاء الفاتورة | يدوي — الأخصائي يضيفها (زر «إنشاء فاتورة للجلسة» يملأ السعر تلقائياً) |
| الجلسات المكتملة القديمة | أُنشئت لها فواتير بالسعر الحالي للأخصائي (مرة واحدة) |
| مرضى بدون تطبيق | مسموح — بالاسم والهاتف داخل المالية فقط |
| تطبيق المريض | صفحة «فواتيري» (قراءة فقط) |
| PDF بترويسة العيادة والشعار | تعديل قادم (مع التقارير — انظر `nabdh_backend/upde.md`) |

## قاعدة البيانات (migration `2026_10_17_000001_create_finance_tables`)

| الجدول | المحتوى |
|--------|---------|
| `appointments.price` | سعر الجلسة وقت الحجز (من `online_session_price` / `in_person_session_price`) |
| `finance_clients` | الحساب المالي لمريض عند أخصائي: `patient_id` (مريض التطبيق) أو اسم/هاتف (بدون تطبيق). `code` تسلسلي لكل أخصائي → `P-001` |
| `invoices` | `number` تسلسلي لكل أخصائي → `INV-0001`، `amount`، `discount`، `issued_at`، `appointment_id` (اختياري) |
| `payments` | `amount`، `method` (`cash` / `card` / `bank_transfer` / `other`)، `paid_at` |
| `expenses` | `category` (`rent` / `equipment` / `salaries` / `supplies` / `utilities` / `other`)، `amount`، `spent_at`، صورة إيصال اختيارية (`storage/app/public/expense_receipts/{therapist}`) |

كل الجداول بـ `softDeletes` — الحذف من التطبيق يُخفي السجل ولا يمسحه.

## الحسابات (لا تُخزَّن — تُحسب دائماً)

- **رصيد المريض** = مجموع (المبلغ − الخصم) للفواتير − مجموع الدفعات
- **الحالة:** `paid` (لا متبقي) · `partial` (دُفع جزء) · `unpaid` (لم يُدفع شيء)
- **حالة كل فاتورة:** دفعات المريض تُوزَّع على فواتيره من الأقدم للأحدث (`FinanceService::allocate`)
- **المستحق** (في الملخص) = مجموع المتبقي على كل المرضى، لكل الأوقات
- **صافي الدخل** للفترة = الدفعات المستلمة − المصاريف
- رصيد زائد عند أخصائي لا يُخصم من مستحق أخصائي آخر (في «فواتيري»)

## API

الأخصائي (`role:therapist`، كل شيء مقيّد بـ `therapist_id` الخاص به) — البادئة `/api/therapist/finance`:

| الطريقة | المسار | ملاحظات |
|---------|--------|---------|
| GET | `summary?from=&to=` | الافتراضي: الشهر الحالي |
| GET | `clients?search=&status=` | البحث بالاسم/الهاتف/`P-002` |
| POST | `clients` | `{patient_id}` أو `{name, phone?, notes?}` — لمريض التطبيق يعيد حسابه إن وُجد |
| GET/PUT/DELETE | `clients/{id}` | الحذف ممنوع إن وُجدت فواتير/دفعات |
| GET | `my-patients` | مرضى الأخصائي (مواعيد + محادثات) مع `client_id` |
| GET/POST | `invoices` (`?from=&to=&search=&status=`) | الخصم ≤ المبلغ |
| PUT/DELETE | `invoices/{id}` | |
| GET/POST | `payments` (`?from=&to=&search=`) | |
| PUT/DELETE | `payments/{id}` | |
| GET/POST | `expenses` (`?from=&to=&category=`) | multipart: `receipt` صورة ≤ 5MB |
| POST/DELETE | `expenses/{id}` | التعديل POST (رفع ملف)، `remove_receipt=1` لحذف الإيصال |

المريض: `GET /api/patient/invoices` → `{summary, accounts: [{therapist_name, invoices, payments, due, …}]}`.

إشعار للمريض (تطبيق) عند فاتورة جديدة (`new_invoice`) أو دفعة (`new_payment`) → يفتح «فواتيري».

## التطبيقات

**الأخصائي** — `lib/features/finance/`:
- الرئيسية → «المالية» (`/finance`): تبويبات المدفوعات (بطاقات المستحق/المدفوع/المرضى + جدول المرضى + سجل الدفعات) · الفواتير · المصاريف (+ صافي الدخل)
- اختيار الفترة: هذا الشهر / الشهر الماضي / آخر 3 أشهر / هذه السنة / مخصصة
- حساب المريض (`/finance/client/:id`): الرصيد، تسجيل دفعة (المبلغ المقترح = المتبقي)، فاتورة جديدة، تعديل/حذف
- تفاصيل الموعد (مؤكد/مكتمل): «إنشاء فاتورة للجلسة» أو «فاتورة الجلسة INV-…»

**المريض** — `lib/features/invoices/` — الملف الشخصي → «فواتيري» (`/invoices`).
