- المالية: تسجيل دفعة/فاتورة/مصروف، وتبويب المصاريف، و«فواتيري» عند المريض

**قبل إصدار تقارير نهائية:** كل أخصائي يُدخل رقم إجازة المزاولة والبيانات بالإنجليزي (الملف الشخصي) واسم العيادة بالإنجليزي والشعار (عياداتي) — حالياً لا أحد أدخلها.

**قرارات معلّقة:**
- 3 ملفات وثائق قديمة في المجلد العام (`storage/app/public/therapist_docs/10` و `/12`) — لم تُحذف بطلب العميل؛ ملف #10 نُسخ للتخزين الخاص وربط بحسابه

- مقترحات: تقارير التقييم للمريض في تطبيقه · مقارنة التحسّن بين تقريرين
- `nabdh_backend/upde.md` (ملاحظات العميل) غير مرفوع — المالية والترويسة منه نُفّذتا
