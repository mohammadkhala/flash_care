# ملف المريض — تقارير التقييم

آخر تحديث: 2026-10-17 — `master` @ `7f8d9ba` — منشور على السيرفر ✅ — **APK لم تُبنَ بعد (بانتظار طلب العميل)**

## الفكرة

- **الأدمن** (لوحة التحكم ← «قوالب التقييم») يحدد التصنيفات (ROM، MMT…) وبنودها (الحركات/العضلات) والمدى الطبيعي، ويجمعها في قوالب.
- **الأخصائي** (التطبيق) يختار المريض والقالب والعيادة، ويُدخل **القيم فقط** (يمين/يسار)، ثم «إنشاء التقرير» → PDF بترويسة العيادة وشعارها.
- القيمة خارج المدى الطبيعي تظهر بالأحمر (في التطبيق أثناء الإدخال وفي الـ PDF). الاختبار الإيجابي بالأحمر.

قرارات العميل: الأخصائي يُدخل القيم والأدمن يحدد البنود · التقرير PDF بالإنجليزية (مثل الصورة المرجعية) · رقم المريض = رقم الحساب المالي `P-001` (يشمل المرضى بدون تطبيق) · التقارير للأخصائي فقط حالياً.

## أنواع الجداول (`assessment_sections.type`)

| النوع | الإدخال | مثال |
|-------|---------|------|
| `bilateral_number` | رقم يمين/يسار + المدى الطبيعي من–إلى | ROM بالدرجات |
| `bilateral_grade` | درجة يمين/يسار من `scale_min` إلى `scale_max` | MMT 0–5، المنعكسات 0–4 |
| `pos_neg` | يمين/يسار: + أو − | الاختبارات الخاصة |
| `single_number` | قيمة واحدة (+ مدى طبيعي اختياري) | الألم 0–10، ثني العمود الفقري |
| `text` | نص لكل بند | الشكوى، الخطة |

## المكتبة الافتراضية (`AssessmentTemplateSeeder` — نُفّذ على السيرفر)

13 تصنيفاً / 84 بنداً / 4 قوالب: تقييم الطرف العلوي، الطرف السفلي، العمود الفقري، تقييم شامل.
المصادر: المدى الطبيعي AAOS (كتف ثني/تبعيد 180، مرفق 150، رسغ 80/70، ورك 120، ركبة 135، كاحل 20/50…)، قوة العضلات Oxford/MRC 0–5، المنعكسات 0–4.
الأمر لا يعمل إن وُجدت تصنيفات (لا يكرر ولا يمسح تعديلات الأدمن).

## قاعدة البيانات (migration `2026_10_17_000002_create_assessment_reports_tables`)

| الجدول | المحتوى |
|--------|---------|
| `assessment_sections` | الاسم ar/en، النوع، الوحدة، حدود المقياس، الترتيب، نشط |
| `assessment_items` | الاسم en (+ar)، `normal_min`/`normal_max`، الترتيب، نشط |
| `assessment_templates` + `assessment_template_section` | القوالب وأقسامها بالترتيب |
| `patient_reports` | الأخصائي، `client_id` (finance_clients)، العيادة، القالب، الموعد (اختياري)، العنوان، التاريخ، **`data` JSON**، ملاحظات، `draft`/`final`، soft delete |
| `clinics.logo_path` | شعار العيادة للترويسة (`storage/app/public/clinic_logos/{therapist}`) |

**`data` نسخة كاملة:** أسماء الأقسام والبنود والمدى الطبيعي تُنسخ في التقرير عند إنشائه. تعديل/حذف القوالب في لوحة التحكم **لا يغيّر التقارير المحفوظة**. القيم تُحفظ بمفتاح `item_id`.

## API (الأخصائي)

| الطريقة | المسار | ملاحظات |
|---------|--------|---------|
| GET | `/therapist/report-templates` | القوالب النشطة بأقسامها وبنودها |
| GET | `/therapist/reports?client_id=&search=` | القائمة (+ `filled`، `abnormal`) |
| POST | `/therapist/reports` | `client_id`, `template_id`, `clinic_id?`, `appointment_id?`, `assessed_at`, `values{item_id:{right,left,value,text}}`, `section_notes{section_id}`, `notes`, `status` |
| GET/PUT/DELETE | `/therapist/reports/{id}` | التعديل يغيّر القيم داخل النسخة المحفوظة |
| GET | `/therapist/reports/{id}/pdf` | PDF (mPDF، يدعم العربي) |
| POST/DELETE | `/therapist/clinics/{id}/logo` | شعار png/jpg ≤ 2MB |

التحقق: الدرجة ضمن المقياس وعدد صحيح، الأرقام ضمن الحدود — رسالة خطأ بالعربي باسم البند.
إصلاح: `POST /therapist/clinics` كان يفشل دائماً (عمود `city` إلزامي) — الآن `address`/`city` اختيارية.

## لوحة التحكم

القائمة ← «📋 قوالب التقييم» (`/admin/assessments`):
- القوالب: إضافة، تعديل الاسم، اختيار الأقسام وترتيبها، إيقاف/حذف
- التصنيفات: إضافة (الاسم، النوع، الوحدة، الحدود)، تعديل البنود في جدول (الاسم en/ar، من–إلى، الترتيب، نشط)، إضافة/حذف بند
- يُفضّل «إيقاف» بدل الحذف

## التطبيق (الأخصائي) — `lib/features/reports/`

- الرئيسية ← «التقارير» (`/reports`): كل التقارير + بحث + «تقرير جديد» (اختيار المريض ← القالب)
- حساب المريض (المالية) ← «تقارير التقييم (ملف المريض)»
- تفاصيل الموعد (مؤكد/مكتمل) ← «تقرير تقييم للجلسة»
- المحرر (`/reports/edit`): المريض والتاريخ والعيادة، أقسام بعناوين زرقاء كالصورة، حقول يمين/يسار، قائمة درجات، +/−، ملاحظات لكل قسم، «حفظ مسودة» / «إنشاء التقرير» (نهائي + فتح PDF)، تنبيه عند الخروج بدون حفظ
- «عياداتي» (`/clinics`): إضافة/تعديل العيادة (الاسم، العنوان، المدينة، الهاتف) + الشعار — لم تكن في التطبيق سابقاً
