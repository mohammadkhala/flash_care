## الترويسة والتقرير (تحديث 2026-10-17 — `521cead`)

بعد بحث في معايير WCPT / APTA / CSP وتعليمات مزاولة مهنة العلاج الطبيعي الفلسطينية رقم (2) لسنة 2023، واعتماد العميل للشكل:

**الترويسة:** يسار = إنجليزي · وسط = الشعار · يمين = عربي. تحت الخط سطر واحد: العنوان (عربي — إنجليزي)، الهاتف، البريد، الموقع.

| | اليسار (EN) | اليمين (AR) | المصدر |
|--|------------|-------------|--------|
| اسم العيادة | `clinics.name_en` | `clinics.name` | عياداتي |
| اسم الأخصائي | `therapists.full_name_en` | `full_name` | الملف الشخصي |
| اللقب · الدرجة | `title_en` · `degree_en` | `title` · `degree` | الملف الشخصي |
| رقم إجازة المزاولة · النقابة | `license_number` · `syndicate_number` | نفس الأرقام بتسمية عربية | الملف الشخصي |
| رقم ترخيص المركز | `clinics.license_number` | | عياداتي |

أي سطر فارغ لا يظهر. بدون بيانات إنجليزية تظهر الجهة العربية فقط.

**التقرير:** عنوان «Physiotherapy Assessment Report» + نوع التقرير (`initial` / `reassessment` / `progress` / `discharge`) + رقم `RPT-0001` لكل أخصائي · المريض: الاسم، `P-xxx`، العمر وتاريخ الميلاد، الجنس، المؤسسة · الإحالة (`self` / `physician` / `other` + الاسم) والتشخيص الطبي · خطة العلاج (جلسات/أسبوع × أسابيع) داخل «Assessment & Plan» · التوقيع مع رقم الإجازة + مكان فارغ للختم (يدوي) · تذييل كل صفحة: «CONFIDENTIAL»، رقم المريض واسمه، رقم التقرير، تاريخ الإصدار (و«Amended» إن عُدّل بعد النهائي)، رقم الصفحة.

**قواعد:**
- التقرير **النهائي** يتطلب رقم إجازة المزاولة في ملف الأخصائي (المسودة لا) — رسالة + زر «فتح الملف الشخصي»
- التقرير يُرجع `letterhead_missing` (الاسم/اللقب بالإنجليزي، اسم العيادة بالإنجليزي، الشعار) → تنبيه مرة واحدة عند «إنشاء التقرير»، لا يمنع
- القانون الفلسطيني يمنع «وصفة علاجية» وطلب الفحوصات/الأشعة → القسم اسمه «Recommendations / Home Program»
- «Assessment & Plan» على السيرفر حُدّث بالـ migration: Clinical Impression → Physiotherapy Diagnosis، وأُضيف Prognosis و Recommendations / Home Program

**أمان:** `PUT /therapist/profile` كان يحفظ كل ما يُرسل (`$request->except`) → كان يمكن للأخصائي تغيير `is_approved` / `rating_average` / `is_featured`. الآن يُحفظ ما تم التحقق منه فقط.

**التحقق:** اختبار مؤقت 30 فحصاً ✅ + PDF من بيانات السيرفر الحقيقية (في الذاكرة) ✅. نسخة احتياطية: `storage/app/db-backup-20261017-pre-letterhead.sql.gz`.

## الفكرة

- **الأدمن** (لوحة التحكم ← «قوالب التقييم») يحدد التصنيفات (ROM، MMT…) وبنودها (الحركات/العضلات) والمدى الطبيعي، ويجمعها في قوالب.
- **الأخصائي** (التطبيق) يختار المريض والقالب والعيادة، ويُدخل **القيم فقط** (يمين/يسار)، ثم «إنشاء التقرير» → PDF بترويسة العيادة وشعارها.
- القيمة خارج المدى الطبيعي تظهر بالأحمر (في التطبيق أثناء الإدخال وفي الـ PDF). الاختبار الإيجابي بالأحمر.

قرارات العميل: الأخصائي يُدخل القيم والأدمن يحدد البنود · التقرير PDF بالإنجليزية (مثل الصورة المرجعية) · رقم المريض = رقم الحساب المالي `P-001` (يشمل المرضى بدون تطبيق) · التقارير للأخصائي فقط حالياً.

## أنواع الجداول (`assessment_sections.type`)

| النوع | الإدخال | مثال |
|-------|---------|------|
| `bilateral_number` | رقم يمين/يسار + المدى الطبيعي من–إلى | ROM بالدرجات |
| `bilateral_grade` | درجة يمين/يسار من `scale_min` إلى `scale_max` | MMT 0–5، المنعكسات 0–4 |
| `pos_neg` | يمين/يسار: + أو − | الاختبارات الخاصة |
| `single_number` | قيمة واحدة (+ مدى طبيعي اختياري) | الألم 0–10، ثني العمود الفقري |
| `text` | نص لكل بند | الشكوى، الخطة |

## المكتبة الافتراضية (`AssessmentTemplateSeeder` — نُفّذ على السيرفر)

13 تصنيفاً / 84 بنداً / 4 قوالب: تقييم الطرف العلوي، الطرف السفلي، العمود الفقري، تقييم شامل.
المصادر: المدى الطبيعي AAOS (كتف ثني/تبعيد 180، مرفق 150، رسغ 80/70، ورك 120، ركبة 135، كاحل 20/50…)، قوة العضلات Oxford/MRC 0–5، المنعكسات 0–4.
الأمر لا يعمل إن وُجدت تصنيفات (لا يكرر ولا يمسح تعديلات الأدمن).

## لوحة التحكم

القائمة ← «📋 قوالب التقييم» (`/admin/assessments`):
- القوالب: إضافة، تعديل الاسم، اختيار الأقسام وترتيبها، إيقاف/حذف
- التصنيفات: إضافة (الاسم، النوع، الوحدة، الحدود)، تعديل البنود في جدول (الاسم en/ar، من–إلى، الترتيب، نشط)، إضافة/حذف بند
- يُفضّل «إيقاف» بدل الحذف

## التطبيق (الأخصائي) — `lib/features/reports/`

- الرئيسية ← «التقارير» (`/reports`): كل التقارير + بحث + «تقرير جديد» (اختيار المريض ← القالب)
- حساب المريض (المالية) ← «تقارير التقييم (ملف المريض)»
- تفاصيل الموعد (مؤكد/مكتمل) ← «تقرير تقييم للجلسة»
- المحرر (`/reports/edit`): المريض والتاريخ والعيادة، أقسام بعناوين زرقاء كالصورة، حقول يمين/يسار، قائمة درجات، +/−، ملاحظات لكل قسم، «حفظ مسودة» / «إنشاء التقرير» (نهائي + فتح PDF)، تنبيه عند الخروج بدون حفظ
- «عياداتي» (`/clinics`): إضافة/تعديل العيادة (الاسم، العنوان، المدينة، الهاتف) + الشعار — لم تكن في التطبيق سابقاً
